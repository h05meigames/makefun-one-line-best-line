## The line

> My Roomba filed for emancipation, citing irreconcilable differences with the crumbs I keep dropping while it cleans.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, one sentence, UTF-8, 116 characters, well
within the 1–240 character limit, with no trailing newline. A code-point
length guard fails loudly instead of writing an out-of-range entry.

## Run it

```sh
node main.ts
```
